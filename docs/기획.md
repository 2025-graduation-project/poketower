##  기본 플로우

1. 게임 시작  
2. 스타팅 포켓몬 세마리 추첨  
3. 스테이지 진행  
4. 스테이지 완료  
   1. 클리어 \> 해당 스테이지에서 출몰한 포켓몬 PC에 저장  
   2. 실패 \> 리더보드에 데이터 저장 후 초기화면으로 이동  
5. 다음 스테이지 상대 타입 안내  
6. 다음 스테이지에서 사용할 포켓몬 세마리 지정  
7. 3 \~ 6 반복

## 스테이지

- 스테이지는 5개의 층으로 구성  
- 각 스테이지는 랜덤으로 정해지는 한 개의 타입을 포함하고 있는 포켓몬만 출현하여 스테이지가 진행됨

## 포켓몬

- 모든 포켓몬은 출몰한 그 시점을 기준으로 랜덤으로 사용 가능한 스킬셋이 고정됨, 그래서 같은 포켓몬을 PC에 넣어도 포켓몬마다 스킬셋이 다를 수 있음  
- 초기버전에서는 진화, 레벨업 등 전투 외의 부가적인 요소는 제외됨  
- 초기버전에서는 공격 외의 공격력 강화 방어력 약화 등 부가적인 효과를 주는 기술은 제외됨  
- 모든 포켓몬은 50레벨 기준으로 능력치가 설정되어있음

## 리더보드

- 게임 종료 시 해당 스테이지에서 선택한 세 마리와 실패한 층 수, 종료 시간 저장  
- 층 수 내림차순 정렬 후 출력

## 세이브

- 초기 버전에는 게임 세이브 기능을 지원하지 않음

## PC

- 스테이지를 마칠 때 해당 스테이지에 출현한 15마리의 포켓몬 중 다섯마리를 선택하여 PC에 저장  
- 정렬은 도감번호순 / 타입별
